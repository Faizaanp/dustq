### 3.6 Root Cause Analysis: The Mathematical Median Reliability Bug
In both Section 2.A and Section 2.B of the science report, the author transcribed the median split-half reliability as:
- Small Model $S$ ($L4d256$): $r_g = 0.4176$ `[code]`
- Medium Model $M$ ($L8d512$): $r_g = 0.1298$ `[code]`

#### Programmatic Root Cause in `dustq/probes.py:279`
Inspection of `dustq/probes.py:279` reveals the faulty implementation:
```python
med = sorted(r_g.values())
return ref, r_g, {"half": half, "r_g_median": med[len(med) // 2] if med else None, "n_groups": len(r_g)}
```
For $N = 12$ layer groups (an even number), Python integer division `12 // 2` yields `6`. In 0-indexed arrays:
- Indices range from $0$ to $11$.
- Index $6$ is the **7th element** (the upper element of the middle pair, rather than the mathematical average of the two middle elements at indices $5$ and $6$).

#### Mathematical Recalculation
1. **Small Model $S$ ($L4d256$)**:
   The 12 group reliabilities sorted in ascending order are:
   ```

   Index 1: +0.007948 (Value emb)
   ```

   - Faulty Selection (`med[6]`): selects `MLP in` = **$0.417564$** (reported as $0.4176$) `[code]`.
