## What was built (commit b52ece1 + close-outs; full suite 41 passed / 4 CUDA-skipped)

1. **SSTE backward** (`dustq/quant.py::_SSTEActQuant`): forward identical to STE; backward
   is the derivative of the Gaussian-smoothed quantizer, dQ/dx = Σ_b φ((x − s·b)/σ)/σ over
   interior grid boundaries (clamp edges excluded — crossings beyond the range are clamped
   away), truncated to ±3 boundaries. **Validated against Monte-Carlo finite differences**
   (test_sste_backward_matches_mc: agreement within MC noise across mid-step/boundary/
   clamp probes; small-σ shape check: mid-step flat, boundary peaked). Wired through
   `RunConfig.ste_mode = "smoothed"` and the site→σ map (qmodel.site_sigma: c_q/c_k/c_v →
   local σ 0.05, o@l → hub 0.2/0.4 by depth, c_fc → hidden 0.2, c_proj → writer 0.2) —
   single source of truth in DUSTQ's DEFAULT_SIGMAS [design choice recorded].
2. **QLinear code caching** (budget-critical): quantized codes recomputed only on in-place
   latent-weight mutation (`tensor._version` invalidation — optimizer.step() bumps it).
   This kills the measured 2.48–3.18× per-forward re-quantization, the largest recoverable
   overhead in the budget (OPEN_QUESTIONS 25). Identity weight STE preserved through the
   cache (test_ste_grad_flows_through_cached_codes).
3. **Integer-code matmul, DUST-only**: the estimator path multiplies exact integer codes
   with fp32 accumulation (|term| ≤ 127·127·4096 < 2^24 — exact; verified vs fp64 to
   ~1e-7 in test_code_matmul_matches_fp64, and vs the exact integer reference bitwise) and
   rescales once in fp32: bf16 rounding can no longer move grid points (the C1 residual is
   closed for the Dust path). BP-STE/BP-SSTE deliberately keep the fake-quant forward in
   train *and* eval for self-consistency (test_exact_path_is_dust_only); the stash is
   cleared on the fake-quant path (stale-value hygiene).
4. **fp32-latent assertion**: bf16-cast latents rejected at construction (arXiv:2610.07853 —
   bf16 latents flip 0.83–1.77% of codes; OPEN_QUESTIONS 27); swap_linear normalizes to
   fp32 while preserving device.
5. **α_b plumbing**: `w1.58a4`/`w1.58a2` route to the `mse_alpha` scheme (A8 keeps absmax per
   the plan); the frozen table (`configs/alpha_calibrated.json`) is produced by
   `scripts/calibrate_alpha.py` (MSE-grid over pooled site activations, per (bits,
   signedness), provenance recorded); smoke/benchmark paths override to absmax so the test
   suite never depends on calibration order.
6. **T5 test suite** (`tests/test_t5.py`, 11 tests): the plan's tests 3 (noise→quantize
   order at o@l, via dual-spy), 4 (captured input = dequantized quantized input, verified
   against an exact upstream-of-all-quantizers recompute), 5 (zero-noise DUSTQ clean pass
   == direct quantized forward, bitwise), 7 (SSTE vs MC), 8 (code-matmul vs fp64 + exact
   integer equality), plus cache invalidation, STE-through-cache, latent assertion,
   DUST-only exact path, and a BP-SSTE training smoke.

  was trained locally before the rule took effect remains on disk (gitignored) as a
