## Findings and deviations

1. **Bug found and fixed by our own tests before any GPU use**: `torch.round` has a zero-gradient backward, so the first version of the activation STE silently severed backprop through the quantizers (finite-but-zero grads; the smoke passed anyway). Fixed with the detach pattern in `dustq/quant.py::ste_quantize`; the STE-identity test now enforces d(out)/dx = 1 exactly.
2. **Phase 0 quantizers use absmax scales at every bit width** (v3.1 4.2's MSE-calibrated α_b arrives in T5, along with the exact integer-code matmul and BP-SSTE). Recorded as a deliberate deferral, not a silent change.
3. **BP-STE smoke lr**: ran at lr 1e-3 / momentum 0.9 (upstream's 0.175/0.98 are for the real protocol; the acceptance criterion is NaN-free steps through the quantized path, not tuned training).
4. **G0 targets now concrete** (Appendix C, 37.7M model): M/1M Dust 256/1k/4k = 6.067/5.934/5.911, backprop 5.959; M/10M 5.231/5.111 vs 4.989. Selected SGD winners are not printed anywhere — the vendored code's tuned defaults are our reproduction values.
5. **Protocol caveat recorded** (OPEN_QUESTIONS 21): the Figure 4 size-study numbers (incl. our S target 5.362) predate the main protocol; the code implements the main protocol (Table 6 matches the code exactly). Expected S offset ~0.02–0.05 is inside G0's 0.08 tolerance.
6. **S head count**: 4 heads at width 256 (head_dim 64 held constant) — derived from Appendix A, not printed; v3.1 4.3 updated.
7. **K=64**: still Tier D only; the paper's printed 64-draw recipe (Appendix E) is now available for it.
8. **Novelty verdict**: niche open as of 2026-10-11; no work found combining activation-space perturbation + low-bit quantized forward + from-scratch pretraining. FOGZO (STE+ZO QAT pretraining) is the must-cite differentiator. Two standing checks: EGGROLL's integer-datatype experiment (full-text read before submission) and monthly Dust-citation re-searches (no citing papers yet; the paper is ~1 week old).
